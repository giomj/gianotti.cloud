Alpha-Phase Hybrid Cloud Mesh — Reference Network Architecture

Edge → comm closet → dual Equinix COLO → OVH → parallel multicloud fork. A BGP mesh of independent pods (each its own AS), interconnected entirely over encrypted WireGuard tunnels, IPv6-addressed, zero-trust throughout. Interim connective fabric while the Beta-phase dedicated quantum-computing datacenter moves through its procurement cycle.

Primary path, in order

  1. Edge → Comm Closet: Intel NUC edge compute tunnels to the on-prem Nutanix comm-closet cluster.
  2. Comm Closet → Equinix A: on-prem Nutanix cluster reaches the first colo Nutanix cluster over WireGuard + eBGP.
  3. Equinix A → OVH: colo hub tunnels onward to the OVH-hosted Nutanix cluster.
  4. OVH → Equinix B: OVH cluster reaches the second colo Nutanix cluster — the multicloud fork hub.
  5. Equinix B → 5 hyperscalers: Equinix B forks in parallel, over five simultaneous WireGuard + eBGP sessions, to DigitalOcean, AWS, Azure, GCP, and IBM Cloud landing zones.

Program phasing

Alpha (this design): commodity edge + colo + public-cloud mesh, deployable near-term with low upfront capital — the environment shown here.

Beta (future): the customer's dedicated, localized datacenter built around the quantum-computing strategy (see the companion Quantum Datacenter reference architecture). That build-out is expected to move through roughly a 64-month procurement / sales cycle — this Alpha mesh is the interim production and proof-of-concept fabric for the duration.

Every link in this diagram — primary and mesh-redundant alike — is a WireGuard tunnel carrying an eBGP session between two independently-numbered pods; there is no unencrypted or unauthenticated path between any two points in the mesh. AS numbers shown are private (RFC 6996, 16-bit range) for the overlay mesh itself; production on-ramps into each hyperscaler's own backbone (AWS Direct Connect, Azure ExpressRoute, Google Cloud Interconnect, IBM Cloud Direct Link) would additionally peer with that provider's public ASN at the cloud edge — see companion document.
